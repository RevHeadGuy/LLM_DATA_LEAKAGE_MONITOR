🔍 Detection Pipeline

1
Input Captured

Text typed, pasted, or dropped into any web input is intercepted in real time.

2
Layer 1 — Regex (instant)

26 patterns detect SSNs, API keys, emails, JWTs, private keys, connection strings and more.

3
Layer 2 — BERT NER (offline)

TinyBERT detects named entities that regex would miss — entirely on-device.

4
Action Taken

Block clears the field. Warn highlights it. Every event is logged to chrome.storage.local.
